Self-hosted web fonts for the landing (no runtime request to Google).

- Archivo (variable, wdth 75-125, wght 400-900): Omnibus-Type. SIL Open Font License 1.1.
- Marcellus (400): Astigmatic. SIL Open Font License 1.1.
- pointless.ttf: shipped with the supplied dojo-landing project (licence not stated there).

The woff2 files are the unicode-range subsets served by the Google Fonts CSS2 API
(https://fonts.googleapis.com/css2?family=Archivo:ital,wdth,wght@0,75..125,400..900&family=Marcellus)
downloaded unmodified. Licences are as listed by Google Fonts; they were not
re-verified against the upstream repositories.
